
# CTU Campus 3D – Classroom Finder Application  
Ứng dụng hỗ trợ tìm vị trí phòng học trong các nhà học tại Khu II Đại học Cần Thơ kết hợp hình ảnh 3D trực quan

---

## 📖 Introduction | Giới thiệu

**English**  
CTU Campus 3D is a web-based application designed to help students and visitors easily locate classrooms and buildings inside Can Tho University (Campus II). Unlike Google Maps, which only shows building coordinates, this system provides **interactive 3D visualization** of both the exterior and interior of campus buildings. It supports searching by classroom codes, finding the shortest path, and displaying detailed building information.

**Tiếng Việt**  
CTU Campus 3D là ứng dụng web giúp sinh viên và khách tham quan dễ dàng tìm vị trí phòng học và nhà học trong Khu II Đại học Cần Thơ. Khác với Google Maps chỉ hiển thị tọa độ tòa nhà, hệ thống này cung cấp **hình ảnh 3D trực quan** cả bên ngoài và bên trong tòa nhà. Ứng dụng hỗ trợ tìm kiếm theo ký hiệu phòng học, tìm đường đi ngắn nhất và hiển thị thông tin chi tiết về địa điểm.

---

## 🎯 Features | Tính năng

- **Interactive 3D Map**: Explore campus buildings in 3D.  
- **Indoor Navigation**: Find classrooms inside multi-floor buildings.  
- **Shortest Path Finder**: Calculate optimal routes inside and outside buildings.  
- **Search by Code**: Locate classrooms using their official codes (e.g., 215/DI).  
- **Personal Positioning**: Identify your current location and navigate from there.  
- **Detailed Information**: View metadata such as building names, codes, and dimensions.  

---

## 🛠️ Technologies Used | Công nghệ sử dụng

- **Frontend**: ReactJS + TailwindCSS  
- **Mapping**: MapLibre GL JS + OpenStreetMap  
- **3D Modeling**: AutoCAD + QGIS  
- **Backend**: NodeJS + ExpressJS  
- **Database**: PostgreSQL + PostGIS

## 🚀 Installation | Cài đặt

**English**  
1. Clone the repository:  
   ```bash
   git clone https://github.com/your-repo/ctu-campus-3d.git
   cd ctu-campus-3d
   ```
2. Install dependencies:  
   ```bash
   npm install
   ```
3. Start the development server:  
   ```bash
   npm run dev
   ```
4. Open your browser at `http://localhost:3000`.

## 📌 Usage Guide | Hướng dẫn sử dụng

**English**  
- **Map Interaction**: Zoom, pan, and click on buildings to view details.  
- **Locate Yourself**: Use the "Locate Me" function to mark your current position.  
- **Find Classrooms**: Enter the classroom code in the search bar to get directions.  
- **Indoor Navigation**: Navigate between floors inside CICT building.  
- **Shortest Path**: Choose start and end points to calculate the optimal route.  

**Tiếng Việt**  
- **Tương tác bản đồ**: Phóng to, thu nhỏ, di chuyển và click vào tòa nhà để xem chi tiết.  
- **Định vị cá nhân**: Sử dụng chức năng "Locate Me" để đánh dấu vị trí hiện tại.  
- **Tìm phòng học**: Nhập ký hiệu phòng học vào thanh tìm kiếm để nhận chỉ đường.  
- **Điều hướng trong nhà**: Di chuyển giữa các tầng bên trong tòa nhà CICT.  
- **Tìm đường ngắn nhất**: Chọn điểm bắt đầu và kết thúc để tính toán đường đi tối ưu.
